CloudLab Latam — CRM Dashboard deploy checklist (Hostinger)
============================================================

Target URL (Laravel): https://cloudlablatam.tech/admin/crm
Target URL (Flask CRM): https://crm.cloudlablatam.tech/admin/crm  (see deploy/FLASK_CRM_DEPLOY.txt)

STEP 2 — Clear caches (REQUIRED)
---------------------------------
Delete via File Manager:
  bootstrap/cache/routes-v7.php
  bootstrap/cache/config.php

Or SSH:
  cd laravel_app
  php artisan route:clear
  php artisan config:clear
  php artisan view:clear
